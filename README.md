# 🌌 JavaVerse 3D · Трёхмерная Вселенная SVG-Эмодзи, Java & JavaScript Виджетов

Интерактивный веб-хаб с фотореалистичной **3D-графикой на Three.js WebGL**, векторными **SVG-эмодзи**, песочницей скриптов **Java & JavaScript**, процедурным **Web Audio синтезатором**, ультра-плавными переходами и богатым набором интерактивных виджетов.

---

## 🌟 Основные разделы и возможности

### 1. 🌌 3D Вселенная (Three.js WebGL 3D Graphics)
- **3D-сцена реального времени**: вращение камеры на 360°, управление мышью и тачем, масштабирование колёсиком мыши.
- **3 уникальных 3D режима**:
  - `☕ 3D Java Кружка`: трёхмерная керамическая чашка с паром и парящими по орбитам обжаренными кофейными зёрнами.
  - `💎 3D Кристалл-Голограмма`: многогранный преломляющий икосаэдр с золотыми орбитальными кольцами и пульсирующим ядром.
  - `🌌 Гипер-Варп`: динамический полёт через звёздное скопление из 800+ 3D-частиц на сверхсветовой скорости.
- Переключение в неоновый режим сетки (**Wireframe**), управление авто-вращением и центрированием.

### 2. 🪐 Гравитационная Песочница SVG-Эмодзи (Physics Sandbox)
- **2D Canvas физика**: гравитация, кинематика, упругие соударения между эмодзи и отскоки от стен.
- **Интерактивные режимы курсора**:
  - `✋ Хватать & Бросать` — перетаскивайте и запускайте эмодзи с ускорением или кликайте в любую точку для спавна.
  - `💨 Отталкивать (Repel)` — курсор создаёт силовое поле и разбрасывает эмодзи.
  - `🧲 Притягивать (Attract)` — курсор работает как гравитационный магнит.
- **Переключатель силы тяжести**: Невесомость (0G), Луна (0.3G), Земля (0.65G), Юпитер (1.4G).
- Процедурные звуки ударов через Web Audio API, зависящие от скорости и массы.

### 3. 🎨 SVG Emoji Studio (Конструктор Векторных Лиц)
- Интерактивный редактор эмодзи с морфингом в реальном времени.
- Выбор формы головы (Круг, Сквиркл, Чашка Java, Пришелец).
- Выбор оттенков кожи и палитр (Gold, Java Roast, Cyan, Violet, Lime, Pink, Onyx).
- Интерактивные глаза (с отслеживанием взгляда за курсором мыши!), солнцезащитные очки, звёзды, сердечки, лазеры.
- Слайдеры сжатия/растяжения (Squash & Stretch), размера глаз и интенсивности неонового свечения.
- Экспорт: **Копирование SVG-кода**, **Скачивание .svg файла**, прямая **отправка созданного эмодзи в физическую песочницу**!

### 4. ☕ Java Virtual Machine & JavaScript Sandbox (Терминал Кода)
- **Режим Java (OpenJDK 21)**: Симуляция компиляции `javac` и выполнения JVM с юмористическими пресетами (`CoffeeBrewService.java`, `JavaVsJavaScript.java`, `DukeAsciiArt.java`).
- **Режим JavaScript (V8 Engine)**: Настоящее безопасное выполнение JS-скриптов прямо в браузере с замером времени выполнения в миллисекундах и доступом к звуковому движку и салюту эмодзи.
- Подсветка номеров строк, очистка терминала, индикаторы статуса.

### 5. 🎮 Мини-Игра: «Ловец Зёрен Java» (Bean Catcher)
- Управление кофейной кружкой Java мышью, тачем или стрелками клавиатуры.
- Ловите падающие золотые кофейные зёрна (+10 очков), звёзды (+25 очков) и огонь (+30 очков).
- Избегайте опасных жуков/багов (-20 очков и потеря сердечка жизни).
- Накопление шкалы кофеина: при 100% включается режим «Caffeine Rush» с удвоением очков и праздничным конфетти!
- Сохранение рекорда в `localStorage`.

### 6. 🎛️ Интерактивные Виджеты & Lo-Fi Станция
- **Lo-Fi Java Beats**: Процедурный генератор битов и тёплых джазовых/lo-fi аккордов на Web Audio API (без внешних MP3-файлов, работает 100% оффлайн) с динамическим SVG-эквалайзером частот!
- **Фокус-Таймер Помодоро**: Круговой плавный SVG-индикатор времени со звуковыми оповещениями и режимами для глубокой работы и кофе-брейка.
- **Погода и Мировые Часы**: Анимированная векторная графика погоды (вращающиеся лучи солнца, капли дождя, молнии грозы, звёздное небо, снег) и точные часы с переключением часовых поясов.
- **Заметки & Стикеры**: Доска задач и идей с выбором стикеров-эмодзи, цветовыми карточками и сохранением в браузере.
- **Синтезатор Звуков**: Интерактивный пульт звуковых эффектов (Coin, Power Up, Laser, Pop, Chime, Java Buzzer).

### 7. ✨ Плавные Переходы и 3D-Эффекты
- Плавный скользящий индикатор навигации (Pill Navigation Indicator).
- 3D-наклон карточек (3D Card Tilt) с расчётом блика при движении мыши.
- 4 темы оформления: **Cyber Neon**, **Java Roast**, **Synthwave**, **Clean Light**.
- Залпы эмодзи-конфетти и частицы.

## 🚀 Установка и Запуск на Сервере

Подробная инструкция вынесена в файл [DEPLOY.md](DEPLOY.md).

### Быстрый запуск в 1 строку (на сервере):
```bash
git clone https://github.com/FsbAidol/VibeCode.git javaverse-3d && cd javaverse-3d && chmod +x deploy.sh && ./deploy.sh
```

### Запуск через Docker:
```bash
docker compose up -d --build
```

### Ручной запуск через Node.js:
```bash
npm install
npm start
```
Сервер будет доступен по адресу: `http://localhost:3000` (или `http://IP_СЕРВЕРА:3000`).
