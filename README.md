# ☕ VibeCode Hub · SVG Эмодзи, Java & JavaScript Виджеты

Современный интерактивный веб-хаб с динамическими векторными **SVG-эмодзи**, песочницей скриптов **Java & JavaScript**, процедурным **Web Audio синтезатором**, ультра-плавными переходами и богатым набором интерактивных виджетов.

---

## 🌟 Основные возможности

### 1. 🪐 Гравитационная Песочница SVG-Эмодзи (Physics Sandbox)
- Реалистичный 2D физический движок на `<canvas>` с сохранением векторной чёткости SVG.
- Настраиваемая гравитация (Невесомость, Луна, Земля, Юпитер).
- Режимы курсора: **Хватать & Бросать**, **Отталкивать (Repel)**, **Притягивать (Attract)**.
- Упругие коллизии между объектами и со стенами с процедурными звуками ударов (Web Audio).
- Кнопки быстрого спавна: дождь кофейных зёрен Java, маскот Duke.

### 2. 🎨 SVG Emoji Studio (Конструктор Векторных Лиц)
- Интерактивный редактор эмодзи с морфингом в реальном времени.
- Выбор формы головы (Круг, Сквиркл, Чашка Java, Пришелец).
- Выбор оттенков кожи и палитр (Gold, Java Roast, Cyan, Violet, Lime, Pink, Onyx).
- Интерактивные глаза (с отслеживанием взгляда за курсором мыши!), солнцезащитные очки, звёзды, сердечки, лазеры.
- Слайдеры сжатия/растяжения (Squash & Stretch), размера глаз и интенсивности неонового свечения.
- Экспорт: **Копирование SVG-кода**, **Скачивание .svg файла**, прямая **отправка созданного эмодзи в физическую песочницу**!

### 3. ☕ Java Virtual Machine & JavaScript Sandbox (Терминал Кода)
- **Режим Java (OpenJDK 21)**: Симуляция компиляции `javac` и выполнения JVM с юмористическими пресетами (`CoffeeBrewService.java`, `JavaVsJavaScript.java`, `DukeAsciiArt.java`).
- **Режим JavaScript (V8 Engine)**: Настоящее безопасное выполнение JS-скриптов прямо в браузере с замером времени выполнения в миллисекундах и доступом к звуковому движку и салюту эмодзи.
- Подсветка номеров строк, очистка терминала, индикаторы статуса.

### 4. 🎮 Мини-Игра: «Ловец Зёрен Java» (Bean Catcher)
- Управление кофейной кружкой Java мышью, тачем или стрелками клавиатуры.
- Ловите падающие золотые кофейные зёрна (+10 очков), звёзды (+25 очков) и огонь (+30 очков).
- Избегайте опасных жуков/багов (-20 очков и потеря сердечка жизни).
- Накопление шкалы кофеина: при 100% включается режим «Caffeine Rush» с удвоением очков и праздничным конфетти!
- Сохранение рекорда в `localStorage`.

### 5. 🎛️ Интерактивные Виджеты & Lo-Fi Станция
- **Lo-Fi Java Beats**: Процедурный генератор битов и тёплых джазовых/lo-fi аккордов на Web Audio API (без внешних MP3-файлов, работает 100% оффлайн) с динамическим SVG-эквалайзером частот!
- **Фокус-Таймер Помодоро**: Круговой плавный SVG-индикатор времени со звуковыми оповещениями и режимами для глубокой работы и кофе-брейка.
- **Погода и Мировые Часы**: Анимированная векторная графика погоды (вращающиеся лучи солнца, капли дождя, молнии грозы, звёздное небо, снег) и точные часы с переключением часовых поясов.
- **Заметки & Стикеры**: Доска задач и идей с выбором стикеров-эмодзи, цветовыми карточками и сохранением в браузере.
- **Синтезатор Звуков**: Интерактивный пульт звуковых эффектов (Coin, Power Up, Laser, Pop, Chime, Java Buzzer).

### 6. ✨ Плавные Переходы и 3D-Эффекты
- Плавный скользящий индикатор навигации (Pill Navigation Indicator).
- 3D-наклон карточек (3D Card Tilt) с расчётом блика при движении мыши.
- 4 темы оформления: **Cyber Neon**, **Java Roast**, **Synthwave**, **Clean Light**.
- Залпы эмодзи-конфетти и частицы.

## 🚀 Запуск и Разработка

В репозитории предусмотрен легковесный Node.js HTTP-сервер без внешних зависимостей:

```bash
# Запуск сервера
npm start
# или
node server.js
```

Сервер автоматически запустится на порту `3000` (`http://0.0.0.0:3000`) с поддержкой CORS и всех современных MIME-типов.

## 📁 Структура Проекта

```
VibeCode/
├── index.html            # Главная страница SPA со всеми панелями и разметкой
├── server.js             # Автономный Node.js HTTP сервер
├── package.json          # Конфигурация и скрипты запуска
├── README.md             # Документация проекта
├── css/
│   ├── main.css          # Дизайн-система, переменные тем, типографика, шапка и сетки
│   ├── animations.css    # Плавные CSS-анимации (пар, лучи, дождь, молния, конфетти)
│   └── widgets.css       # Стили всех интерактивных виджетов
└── js/
    ├── app.js            # Главный контроллер, темы, вкладки, глобальные события
    ├── audio.js          # Синтезатор Web Audio API (звуковые эффекты и Lo-Fi музыка)
    ├── emoji-data.js     # Векторная библиотека SVG-эмодзи и компоненты конструктора
    ├── utils/
    │   ├── confetti.js   # Залпы эмодзи-конфетти и физика частиц
    │   └── tilt.js       # 3D-наклон карточек с динамическим бликом
    └── widgets/
        ├── emoji-studio.js   # SVG Конструктор лиц
        ├── physics.js        # 2D Гравитационная песочница
        ├── java-runner.js    # Терминал Java & JavaScript
        ├── lofi-player.js    # Генератор Lo-Fi и визуализатор частот
        ├── pomodoro.js       # Круговой таймер фокусировки
        ├── weather-clock.js  # Анимированная погода и часы
        ├── bean-catcher.js   # Аркадная мини-игра с кружкой Java
        └── notes.js          # Быстрые заметки со стикерами
```
